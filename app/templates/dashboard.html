How to connect a real camera

Option A — CCTV / IP Camera (RTSP)

Set CAMERA_RTSP_URL in Railway environment variables:

rtsp://admin:pass@192.168.1.10:554/stream1

Hikvision / Dahua / Reolink / TP-Link all work

Option B — Phone IP Camera (HTTP)

Install IP Webcam (Android) or EpocCam (iOS), then set:

CAMERA_URL=http://192.168.1.xxx:8080/shot.jpg

Phone must be on the same network as the server, or use a tunnel (ngrok)
