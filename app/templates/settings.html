▶ How to get a tunnel URL (click to expand)

Why is this needed?

Railway is a cloud server. It cannot reach 192.168.x.x — those are private IPs on your home network. You need a tunnel that bridges your home camera to a public internet URL.

📱 Phone Cam (DroidCam / IP Webcam)

  1. Install IP Webcam (Android) or DroidCam on your phone
  2. Start the server — it shows a local IP like 192.168.1.50:8080
  3. On a PC on the same Wi-Fi, open a terminal and run:
    npx bore local 8080 --to bore.pub (free, no account needed)
  4. It gives you a URL like http://bore.pub:XXXXX
  5. For IP Webcam paste: http://bore.pub:XXXXX/video
    For DroidCam paste: http://bore.pub:XXXXX/video

📷 CCTV / NVR via RTSP

  1. Log into your router admin page
  2. Port-forward external port 554 → your camera's local IP port 554
  3. Find your public IP at whatismyip.com
  4. Paste the RTSP URL below, e.g.:
    rtsp://admin:password@YOUR_PUBLIC_IP:554/stream1

Tip: Tunnels like bore.pub give a new URL each time. For a permanent URL use ngrok (free tier) or Cloudflare Tunnel.
